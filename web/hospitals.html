Hospital policy database

Every policy here was pulled from the hospital's own website through Bright Data (SERP API to find it, Web Unlocker to fetch the page and its policy PDFs), read by Claude, and every quote was checked word-for-word against the fetched text before any number was used. Raw crawl artifacts are linked under each hospital.

Same bill, different hospitals

One patient, one bill, one income. Only the hospital's own policy changes.

Policies on record

Policies rarely change, so they are stored and rechecked: a recheck refetches the same documents, compares content hashes, and only re-reads the policy if something changed.
